# Aquabill-App
Aquabill Application for android
  The official app of the **SVOB Water Billing System**, San Vicente.                                                                                                                                                           
  See your water bills, pay with GCash, track your usage, and request repairs, all in one app.
  Works on Android 7.0 or newer. Not available for iPhone.
  ## 📥 Download                                                                                                                                                                                                                    
  **[⬇ Download AquaBill](https://github.com/RayJeanier/Aquabill-App/releases/latest/download/AquaBill.apk)**                                                                                                                       
                                                                                                                                                                                                                                    
  ## 📲 How to install                                                                                                                                                                                                              
  1. Tap the download link above.                                                                                                                                                                                                   
  2. Open the downloaded **AquaBill.apk**. It's in your notifications or your **Downloads** folder.                                                                                                                                 
  3. If your phone says it can't install unknown apps, tap **Settings**, turn on **Allow from this source**, then go back.                                                                                                          
  4. If Google Play Protect warns you, tap **More details → Install anyway**.                                                                                                                                                       
  5. Open **AquaBill** and sign in with your User ID and password.                                                                                                                                                                  
                                                                                                                                                                                                                                    
  ## 🔄 Updating                                                                                                                                                                                                                    
  Download from the same link and install over the old app. Nothing is lost.                                                                                                                                                        
  If you installed an early test version, uninstall it first (only once).
